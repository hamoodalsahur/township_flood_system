# V2.13 resident reporting usability

The geographic demo form shared by the resident road explorer and management maps now gives a simple three-step guide, character count, location and optional sample-image validation, disabled-state feedback, progress text for saving and private photo attachment, and a reset file picker after submission. Client rules mirror the existing server-side fictional research rectangle and 8–400 character / JPEG-PNG 5 MB limits; server validation remains authoritative. A failed photo upload reports partial success without hiding the fact the fictional report was saved.

No API, SQLite schema, reseeding/reset, geographic import, map validation claim, public evidence exposure, new account permissions or road state automation. No destructive db:push advice. Test incomplete and valid forms, sample photo error/attachment, progress feedback, and the original evidence privacy review on the combined V2.13 acceptance branch.
