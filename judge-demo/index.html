How the full system works

The actual FYP project includes a local Next.js management website and Expo iPhone app. Residents can submit fictional reports and sample photos, while an operator separately reviews reports and explicitly authorizes photo visibility.

This independent public prototype simulates the review decision on-page without authentication. It does not expose private photos, operator keys, your laptop's SQLite database, or a remote API.

Judge walkthrough: pick a map pin → filter by category → inspect review status → add a fictional report → select it → mark it reviewed or rejected → reset.
